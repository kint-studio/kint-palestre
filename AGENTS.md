# KINT Palestre

Landing statica per le palestre, costruita con il metodo del sito principale (`KINT-codice-completo`): HTML, CSS e JS senza framework.

- `npm test` esegue i test; `npm run dev` serve su http://localhost:3102/palestre/.
- I file in `assets/` presenti anche nel principale devono restare identici (`tests/shared-assets.test.js`). Le varianti stanno in `assets/palestre/`.
- Nessuna dipendenza di runtime: `package.json` ha solo `devDependencies`.
- Commit in italiano; niente push senza richiesta.
